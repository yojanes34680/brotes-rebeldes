# Brotes Rebeldes

Juego de defensa con fusión: planta, fusiona y detén al enjambre de insectos.

**Jugar:** https://yojanes34680.github.io/brotes-rebeldes/

- Funciona en el navegador del computador y del teléfono, también **sin conexión**.
- Se puede **instalar como app**: en Chrome o Edge, botón *Instalar*; en iPhone, *Compartir → Añadir a pantalla de inicio*.
- En español e inglés (*Opciones → Idioma*).

Todo el arte se dibuja con código, la música se sintetiza en el propio juego y no usa recursos de otros juegos.
Créditos completos en *Opciones → Créditos*.
